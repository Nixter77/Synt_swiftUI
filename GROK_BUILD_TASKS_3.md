## Найденные баги мод-матрицы (аудит кода, перепроверено на 7a879d9 — всё ещё актуально)
Источник × цель — 3 × 11 = 33 пары. В рендере `switch entry.destination` обрабатывает только `.pitch1 .pitch2 .amp .pan`, всё остальное уходит в `default: break`. Это подтверждает комментарий в `PresetAuthoring.liveDestinations`: «Cutoff / PWM / mix entries are stored and silent».

| Цель | Статус | Почему |
|---|---|---|
| Pitch OSC1 / OSC2 | работает | `osc*Freq *= 2^(clamp(mod,±2))`: amount 1.0 = ±1 октава. В UI единиц нет, поэтому непонятно |
| Amplitude | работает | `amplitude *= max(0, 1+ampMod)` |
| Pan | работает | `pan = v.pan + panMod` (стоит проверить clamp) |
| **Filter Cutoff** | **молчит** | `default: break`. Фильтр общий (`filterL.cutoff` считается один раз на сэмпл до цикла голосов), пер-голосовой модуляции нет |
| **Resonance** | **молчит** | то же |
| **PWM OSC1 / OSC2** | **молчит** | то же |
| **LFO Rate** | **молчит** | то же |
| **LFO Depth** | **молчит** | то же |
| **Osc Mix** | **молчит** | то же |

Итого 21 из 33 пар (7 целей × 3 источника) ничего не делают. Ещё три проблемы, из-за которых «непонятно, что делает»:
1. `LFO.getValue` возвращает `0`, если LFO выключен (`guard enabled`). Поэтому строки матрицы с источником LFO 1 молчат при выключенном тумблере LFO. А при включённом LFO он дополнительно модулирует свою цель (`lfoTarget`). Отдельно использовать LFO только для матрицы нельзя.
2. `Env 1 (Amp)` однополярный (0…1), LFO и Velocity — нет. Нигде это не показано.
3. Ручка Amount — `KnobView` с `scaleEffect(0.8)` и форматом `%.1f`: значение 0.05 выглядит как «0.1»/«0.0», знак и единицы не видны. Кнопка «+» всегда добавляет `LFO 1 → Pitch OSC1, 0`, то есть строку, которая ничего не делает.

Фабричные пресеты используют только `velocity→amp`, `lfo1→pan`, `lfo1→amp`. Поэтому починка «молчащих» целей их звук не меняет. Это должен подтвердить golden-тест.

## Задача 3 — Мод-матрица: все цели работают, понятный UI

**Шаги — звук:**
1. Обработать все цели в `switch` без `default`, чтобы компилятор ловил новые случаи:
